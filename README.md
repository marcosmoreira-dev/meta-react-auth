# Meta React Auth

Sistema de autenticação frontend desenvolvido em React com TypeScript, utilizando Context API, React Router, Tailwind CSS e shadcn/ui.

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como solução para um case técnico utilizando React.

O sistema possui:

- Tela de login
- Área administrativa protegida
- Autenticação frontend
- Dark/Light Mode
- Rotas protegidas
- Dashboard administrativa
- Componentização reutilizável

---

## 🚀 Tecnologias Utilizadas

- React
- TypeScript
- Vite
- React Router DOM
- Tailwind CSS
- shadcn/ui
- Context API
- next-themes

## 🛠️ Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/meta-react-auth.git
```

---

### 2. Acesse a pasta do projeto

```bash
cd meta-react-auth
```

---

### 3. Instale as dependências

```bash
npm install
```

---

### 4. Execute o projeto

```bash
npm run dev
```
